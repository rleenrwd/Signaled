# Marcus Johnson — Administrator Persona

## Profile

- **Role:** Administrator
- **Organization:** Large public-sector agency
- **Department:** Information Technology
- **Experience:** 6 years in enterprise systems administration

## Background

Marcus manages Signaled’s users, access, configuration, and system-level settings. He is responsible for keeping the platform secure, properly configured, and available to the teams that rely on it.

## Goals

- Manage user access efficiently
- Enforce least-privilege permissions
- Keep system configuration consistent
- Support secure integrations and services
- Maintain platform reliability

## Pain Points

- Manual access-management processes
- Inconsistent permissions between users
- Poor visibility into configuration changes
- Hard-to-troubleshoot system issues
- Too many credentials or settings managed separately

## Typical Tasks

- Create and manage user accounts
- Assign roles and permissions
- Configure system settings
- Manage integrations and service access
- Review system activity and audit records
- Support troubleshooting and access issues

## Quote

> “I need to keep the platform secure and reliable without making access and configuration harder than they need to be.”
